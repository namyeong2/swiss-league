# 스위스 리그전

교실에서 쓰는 스위스 방식 리그전 진행 도구입니다. 토너먼트처럼 첫 판에 지면 끝나는 것이 아니라, 모든 학생이 같은 횟수로 경기하고 승수가 같은 친구끼리 만납니다.

## 바로 쓰기

- 웹에서 열기: https://namyeong2.github.io/swiss-league/
- 또는 `index.html` 파일을 내려받아 브라우저로 열면 됩니다. 설치할 것은 없습니다.

## 주요 기능

- 참가 번호와 결석생 번호를 넣으면 결석생을 빼고 시작합니다.
- 라운드 수를 인원에 맞게 추천합니다. 직접 바꿀 수도 있습니다.
- 2라운드부터 승수가 같은 학생끼리 짝을 짓고, 이미 만난 친구와는 다시 붙지 않게 합니다.
- 인원이 홀수면 라운드마다 한 명씩 쉽니다. 쉬는 판은 승리로 세지 않고, 한 학생이 두 번 쉬지 않습니다.
- 순위는 승수만으로 정하고, 승수가 같으면 공동 순위입니다.
- 최종 순위 화면에서 '순위 결정전'을 고르면 공동 순위끼리 겨뤄 모든 순위를 가립니다. 결정전 결과는 같은 공동 묶음 안에서만 순위를 바꿉니다.
- 이긴 번호를 다시 누르면 취소되고, 이전 라운드로 되돌릴 수 있습니다.
- 효과음이 있으며 🔊 버튼으로 끌 수 있습니다.

## 개인 정보

학생 이름을 쓰지 않고 번호로만 진행합니다. 입력한 내용은 어디에도 저장되거나 전송되지 않습니다. (소리 켜기/끄기 설정만 쓰는 브라우저에 기억됩니다.)
